# GPhotos Cam website

Homepage and privacy policy for GPhotos Cam, an iPhone camera app that uploads
photos straight to Google Photos. Google requires both pages to publish the
app's OAuth consent screen.

Published with GitHub Pages:

- Home: https://jerry426.github.io/gphotos-cam/
- Privacy policy: https://jerry426.github.io/gphotos-cam/privacy.html

The app's code lives in a separate private repository.
